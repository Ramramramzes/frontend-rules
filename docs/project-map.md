# Карта проекта

Одна короткая карта `MAP.md` в корне проекта подходит и Cursor, и Codex. Если в проекте уже ведётся карта, используйте её. Карта отвечает на вопрос «где начать искать» и указывает на код.

## Первая карта

Возьмите [шаблон MAP.md](../templates/MAP.md) или попросите агента составить карту по нему. Начните с маршрутов, моделей Effector, OpenAPI, библиотеки компонентов и темы. Добавляйте только проверенные ссылки и устойчивые ориентиры, например `AppRouter` или `formSubmitted`. Пишите путь от корня проекта. Большому разделу можно дать собственную карту и оставить на неё ссылку в корневой.

Пример запроса агенту:

> Создай короткий MAP.md для этого проекта. Найди точки входа, маршруты, модели Effector, источник и генерацию OpenAPI, общие компоненты и тему. У каждой записи укажи реальный путь и имя, по которому её можно найти через rg. Ссылайся на существующие документы. Обозначь области, которые ещё не проверены.

Если задача меняет маршрут, публичное имя или расположение файла, обновите соответствующую строку карты. При расхождении с картой доверяйте исходному коду.

## Дополнительные инструменты

| Инструмент | Когда использовать |
| --- | --- |
| [agent-project-map](https://github.com/ZYY817/agent-project-map/blob/main/README.md) | Основной подход. Короткие карты с поисковыми ориентирами обновляются вместе с изменениями кода |
| [project-map](https://github.com/fankcoder/project-map) | Разовый обзор большого незнакомого репозитория. Из сгенерированной `.project-map/project-map.md` можно взять полезные ориентиры для основной карты |
| [Graphify](https://github.com/Graphify-Labs/graphify) | Запросы о связях между модулями, когда обычного поиска недостаточно. Используйте локальный граф исходников и сверяйте связи с кодом |
| [cursor-docs-hook](https://github.com/beautyfree/cursor-docs-hook) | Подходит для команды, которая хочет автоматически вести `docs/INDEX.md`. В этой базе карта обновляется в рамках текущей задачи, поэтому фоновый проход не требуется |

Для запуска Graphify по запросу можно установить CLI через `uv` и построить локальный граф. Команды выполняются в корне проекта. Результаты графа оставляйте локально. [Документация Graphify](https://github.com/Graphify-Labs/graphify#install).

```bash
uv tool install graphifyy
GRAPHIFY_BACKEND=none graphify extract . --code-only
graphify query "Как маршрут связан с моделью состояния и API?"
```

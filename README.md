Установщик подключает три файла из `rules/`. Общие принципы Карпатого действуют для работы с кодом. Остальные правила относятся к фронтенд-задачам.

## Глобальное подключение

Из корня этого репозитория:

```bash
python3 scripts/install.py
```

Установщик добавляет правила в отдельный блок глобального `~/.codex/AGENTS.md`, сохраняя остальной текст. Если задан `CODEX_HOME`, используется этот каталог. При наличии непустого `AGENTS.override.md` установщик обновляет его. При изменении существующего файла создаётся резервная копия рядом с ним. Повторный запуск обновляет тот же блок, в том числе если в нём раньше были только правила Карпатого.

На macOS скопируйте общий текст в буфер обмена:

```bash
python3 scripts/install.py --print-rules | pbcopy
```

В Cursor откройте **Customize → Rules → User Rules** и вставьте текст. Если правила Карпатого уже добавлены из этой базы, замените их общим текстом. Остальные пользовательские правила сохраните.

Установка не выполняет коммиты и не публикует изменения. Чтобы перенести подготовленные файлы в другой уже клонированный пустой репозиторий, можно запустить:

```bash
python3 scripts/install.py --repo "$HOME/Desktop/frontend-rules"
```

В этом режиме копируются только файлы из списка `FILES` установщика, включая правило компонентов и документ процесса. Отличающиеся существующие файлы не перезаписываются; каталог `.git` не изменяется.

## Обновление и проверка

После изменения файлов в `rules/` повторите установку для Codex и обновите текст User Rules в Cursor.

В новой сессии каждого инструмента проверьте два разных проекта: попросите назвать действующие общие принципы. Для Codex можно дополнительно проверить наличие блока `frontend-rules:karpathy` в глобальном файле; для Cursor — сохранённый текст в User Rules. Это проверяет подключение; качество соблюдения правил оценивается по реальным изменениям и результатам проверок.

В `AGENTS.md` конкретного проекта указывайте его структуру, библиотеки, команды и ограничения.
